### 🚀 Featured Projects (Bridging DE & DA)

#### 🚇 [Real-Time Kraków Public Transit Delay Analytics](https://github.com/10Nikus/Komunikacja-KRK)
Designed and deployed an automated, serverless ETL pipeline utilizing GitHub Actions as a lightweight orchestrator to ingest and process real-time public transit API streams from Kraków's transport network 24/7. Structured and optimized target table schemas within a Google BigQuery cloud data warehouse, ensuring high availability, strict data integrity, and efficient partition tuning. Designed and deployed an interactive analytical dashboard in Looker Studio to visualize live traffic delays, identify peak congestion bottlenecks, and track operational performance metrics within a cloud data warehouse environment.

#### 🐙 [GitHub Open Source Ecosystem Analysis](https://github.com/10Nikus/GitHub-Open-Source-Ecosystem-Analysis)
Processed, cleaned, and aggregated 11 years of historical developer activity from the multi-terabyte GitHub Public Dataset within Google BigQuery using highly optimized SQL queries to minimize cloud compute costs. Focused heavily on cloud query optimization, indexing strategies, and cost-reduction tuning to transform massive raw semi-structured event logs into performant relational models. Designed and deployed a comprehensive Tableau dashboard to visualize global open-source evolution, programming language lifecycles, and developer behavioral patterns, converting raw data into actionable spatial-temporal insights.

#### 📦 [InPost Logistics & Geo-Analytics Pipeline](https://github.com/10Nikus/Inpost)
Engineered an end-to-end data pipeline integrating external REST API data on parcel lockers, geolocation coordinates, and urban air quality metrics to guarantee continuous ingestion. Applied unsupervised machine learning by implementing K-Means clustering for geographic market segmentation to isolate distinct regional utilization profiles. Developed an interactive geospatial dashboard using Streamlit and PyDeck to monitor network congestion and operational KPIs, delivering data-driven infrastructure and fleet optimization solutions.

#### 💼 [Startup Ecosystem & Market Growth Analysis](https://github.com/10Nikus/startup-analysis)
Conducted an exploratory and quantitative data analysis of global startup ecosystems, funding rounds, and investment trajectories using Python and SQL data manipulation techniques. Cleaned and processed raw, multi-source business datasets to evaluate venture capital distribution, industry-specific success rates, and company valuation trends over time. Transformed complex financial and operational metrics into comprehensive statistical plots and visualizations to model growth patterns and identify high-potential market opportunities.

#### 🧘 [Wellness Smart Device Consumer Analytics](https://github.com/10Nikus/wellness-company)
Analyzed smart device fitness tracking and biometric data from a health-focused wellness company to identify core consumer usage trends and behavioral patterns. Cleaned, transformed, and aggregated disparate datasets tracking daily activity metrics, sleep cycles, and caloric expenditure to build comprehensive user profiles and validate data consistency. Synthesized data-driven insights into high-level marketing strategies and product optimization recommendations to drive targeted customer acquisition and sustainable business growth.
